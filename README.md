# Imran Beyan - Personal Portfolio Website

An ultra-modern, editorial personal portfolio website tailored for **Imran Beyan**, designed with inspiration from high-end minimalist design aesthetics (warm peach & terracotta tones, frosted glassmorphism, organic radial halos, and clean typography).

---

## 🌟 Key Features

1. **Editorial Luxury Visual Identity**:
   - Recreated the warm peach, terracotta, and cream aesthetic from the reference designs (`alexmorgan.design`).
   - Circular organic hero portrait with a soft glowing halo and floating frosted glass status card: *"Available for collaborations"*.
   - Responsive pill buttons, micro-interactions, and smooth hover effects.

2. **Personalized Profile & Photos**:
   - Integrates all 5 personal photos provided by Imran with an interactive **Avatar Switcher** directly in the hero and an interactive **Photo Gallery**.

3. **Special School Student & Mathematical Roots**:
   - Highlights Imran's background in a specialized school for gifted minds and his problem-solving approach.
   - **Interactive Mathematical Lab**: Live solvers demonstrating fast matrix exponentiation Fibonacci $O(\log n)$, quadratic extremum discovery, and 3x3 Sobel edge convolution kernels.

4. **Advanced AI & Multi-Agent Showcase**:
   - **Interactive LangGraph Simulator**: Visualizes multi-agent planning, specialized tool execution (PyTorch / Python / SQL), reflection loops, and state graph updates in real time.

5. **Full Technical Stack Showcase**:
   - **Languages**: Python, SQL, JavaScript, HTML5, CSS3.
   - **AI / Deep Learning**: PyTorch, Scikit-learn, Computer Vision, OpenCV.
   - **Agentic Frameworks**: LangChain, LangGraph, Autonomous Multi-Agent Architectures.
   - **Web Frameworks**: Django, REST APIs, Relational Database schemas.

## 🚀 How to Publish to GitHub & Vercel (`imran17.vercel.app`)

### Step 1: Create a Repository on GitHub
1. Go to [github.com/new](https://github.com/new).
2. Enter repository name: **`imran17`** (or `imran-portfolio`).
3. Set visibility to **Public** and leave all checkboxes unchecked.
4. Click **Create repository**.

### Step 2: Push Your Code
Double-click `push_to_github.bat` inside this directory, or run in terminal:
```cmd
push_to_github.bat
```
*(Git will prompt you to authorize your GitHub account `imranbeyan162-collab` via your browser if not already authenticated)*.

### Step 3: Publish as `imran17.vercel.app`
1. Go to [vercel.com/new](https://vercel.com/new).
2. Connect your GitHub account and click **Import** next to `imran17`.
3. In **Project Name**, enter: **`imran17`**.
4. Click **Deploy**.
5. Your website will be live globally at **https://imran17.vercel.app**!
